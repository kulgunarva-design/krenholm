# Kreenholmi Meistride Maja

Откройте index.html в браузере. Это готовый статический сайт; все изображения находятся в комплекте.

Основной сайт также сохранён в C:\krenholm\dist. Папка исходных фотографий C:\krenholm\img не изменялась.

## Контакты
Заполните config.js: email, phone, address. Сейчас на странице показано сообщение, что контакты появятся позже. Неуказанные реквизиты не выдуманы.

## QR для табличек
Сначала нужен постоянный публичный HTTPS-адрес сайта. Затем tools/make_qr.py создаст чёрно-белый SVG для печати и PNG с белыми полями.

Запуск: python tools/make_qr.py https://ВАШ-ДОМЕН
Зависимости Python: reportlab, Pillow.

В комплект намеренно не включён QR с вымышленным или закрытым адресом. После генерации проверьте код камерой телефона на пробной распечатке.

## Фотографии
Использованы все 13 предоставленных снимков. Подписи описательные, без неподтверждённых дат и имён. Кирпичный фон — декоративная сгенерированная текстура, не фотография кладки здания.

## Проверка
Проверено: 13 фотографий в галерее, открытие окна, стрелки и Escape, отсутствие ошибок JavaScript, отсутствие горизонтальной прокрутки на ширине 390 пикселей.

Онлайн-публикация не завершена из-за сбоя среды доступа. Для обычного хостинга загрузите index.html, style.css, app.js, photos.js, config.js и папку img.
